فایل و عملیات

فایلی انتخاب نشده است.
از میان نتورک‌های فعال همان مرکز، قدیمی‌ترین یا همه را غیرفعال می‌کند.
Origin از «کد پرنت»، Destination از «نام مرکز» و تاریخ‌ها از Excel خوانده می‌شوند.
Hub Network با Start Hub = نام پرنت و End Hub = نام مرکز انتخاب می‌شود و تاریخ ظرفیت ثبت می‌شود.
فقط رکورد غیرفعال با تطبیق مرکز و پرنت را فعال می‌کند.
می‌تواند مستقل یا بعد از غیرفعال‌سازی نتورک اجرا شود.
